How OrderApp Works

Simple order creation with asynchronous Kafka processing.

🛒 Create Order

Customers select products and create an order through the web interface.

💾 Store Order

Spring Data JPA stores the order and product information in MySQL.

📨 Kafka Event

The application publishes an order-created event to Apache Kafka.

⚙️ Process Order

The Kafka consumer receives the event and updates the order status.
